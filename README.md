# smarzban/tap

Homebrew tap for [tsk](https://gettsk.sh), a terminal task board for you and your agents.

```sh
brew install smarzban/tap/tsk
```

Upgrade with `brew update && brew upgrade tsk`. The formula pins each release's platform archive and SHA-256; it is generated by `scripts/release.py` in [smarzban/herdr-tsk](https://github.com/smarzban/herdr-tsk) and committed here after the release is published.
